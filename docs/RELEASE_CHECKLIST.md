# Release checklist

- [ ] Tests, type checking, lint, and production build pass.
- [ ] Mainnet contract ID matches the deployment manifest.
- [ ] Public app URL opens without authentication.
- [ ] Demo mode is clearly labelled and cannot produce false Mainnet proof.
- [ ] Recipient, amount, asset, and memo are visible before signing.
- [ ] Failed, pending, and duplicate transaction states are handled.
- [ ] README links and latest functional transaction are current.
- [ ] Rollback owner and previous deployment are known.

Record the release commit and Vercel deployment URL in the submission evidence.
